# @wavv/sdk

Embed WAVV's dialer, messenger and callboards in your product.

```sh
npm install @wavv/sdk
```

## Documentation

Guides and the full API reference are at **[sdk.wavv.com](https://sdk.wavv.com)**. Sign up for a WAVV
developer account there to get access.

The same reference ships in this package as **`REFERENCE.md`** (`node_modules/@wavv/sdk/REFERENCE.md`), matching
the version you installed and readable without a login. AI coding assistants: read it before writing an integration.
It covers the SDK functions, minting tokens on your backend, SDK keys versus team keys, and webhooks.
