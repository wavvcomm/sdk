# @wavv/sdk

Embed WAVV's dialer, messenger and callboards in your product.

```sh
npm install @wavv/sdk
```

## Documentation

Guides and the full API reference are at **[sdk.wavv.com](https://sdk.wavv.com)**. Sign up for a WAVV
developer account there to get access.

## About this repository

This repository is a mirror of the `sdk/` directory of WAVV's main repository, published by WAVV's
release tooling. Each tag `v<version>` is the source of that version's npm release. Pull requests are
not accepted here; to report a problem, contact WAVV through [sdk.wavv.com](https://sdk.wavv.com).
